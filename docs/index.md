# OMAIB Public Docs

[![Docs](https://img.shields.io/badge/docs-public-blue)](https://github.com/omaib/omaib-docs)

Public-facing documentation source for OMAIB.

## What Belongs Here

- User-facing guides
- Public API usage
- Public benchmark/methodology notes
- Governance summaries intended for external readers

## What Does Not Belong Here

- Secrets, tokens, keys, or private infrastructure details
- Internal incident runbooks
- Internal release gates and escalation procedures

## Repo Docs

Each code repository still maintains a `docs/` folder for implementation-specific docs. This repo is the public
publication layer.
